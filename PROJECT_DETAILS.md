# PROJECT_DETAILS.md — AI-Powered Study Companion (RAG-First MVP)

## 1. Executive Summary & Mission
The **AI-Powered Study Companion (RAG-First MVP)** is a web-based learning application built from scratch using Next.js (App Router), TypeScript, Tailwind CSS, MongoDB Atlas Vector Search, and the Google Gemini API (`gemini-3.5-flash-lite` and `gemini-embedding-001`). 

The core objective is a reliable, secure, source-grounded Retrieval-Augmented Generation (RAG) pipeline over student course materials (PDF, TXT) that enables students to ask questions, view citations, generate summaries, create flashcards, and take auto-graded practice quizzes without fabrication or hallucination.

---

## 2. Technology Stack & Architecture

- **Frontend & Routing:** Next.js 14 (App Router), React 18, Tailwind CSS, PostCSS.
- **Database & Vector Store:** MongoDB Atlas (`mongodb` driver) with MongoDB Atlas Vector Search index (`vector_index`).
- **AI & Embeddings:** Google Gen AI SDK (`@google/generative-ai`), `gemini-3.5-flash-lite` (text generation) and `gemini-embedding-001` (768-dimensional embeddings with explicit `RETRIEVAL_DOCUMENT` and `RETRIEVAL_QUERY` task types).
- **Document Parsing:** `pdf-parse` for PDF text extraction.
- **Testing:** Jest & ts-jest.

---

## 3. Project Structure & Services

- **`src/app/`**:
  - `layout.tsx`: Root layout with Tailwind CSS styling and metadata.
  - `globals.css`: Global styles and Tailwind directives.
  - `page.tsx`: Full responsive study dashboard (Chat, Document Library, Summaries, Flashcards, Quizzes, and Citation Preview Modal).
  - `api/upload/route.ts`: Server-side file upload handler with MIME type validation, 15MB size limits, and ingestion triggering.
  - `api/documents/route.ts`: Document listing and cascading deletion endpoint.
  - `api/qa/route.ts`: Grounded RAG Q&A endpoint.
  - `api/study/route.ts`: Study tools endpoint for summaries, flashcards, and quiz generation/grading.
- **`src/services/`**:
  - `db.ts`: Robust MongoDB connection singleton with TLS and timeout options.
  - `gemini.ts`: Centralized Gemini client configuration (`gemini-3.5-flash-lite`, `gemini-embedding-001` at 768 dimensions).
  - `ingestion.ts`: Text extraction (PDF/TXT), validation, recursive chunking with overlap, embedding persistence, and deletion.
  - `retrieval.ts`: Semantic vector search aggregation pipeline over MongoDB Atlas Vector Search with document filtering and collection-scan fallback.
  - `rag.ts`: Grounded QA prompt assembly, LLM generation, and strict citation validation.
  - `study.ts`: Grounded summaries, flashcard generation, quiz question generation, and quiz auto-grading.
- **`src/types/`**:
  - `index.ts`: Centralized TypeScript interfaces (`DocumentRecord`, `ChunkRecord`, `Citation`, `RAGAnswer`, `SummaryResult`, `Flashcard`, `QuizQuestion`, `QuizResult`).
- **`src/tests/`**:
  - `service.test.ts`: Unit tests for chunking, text extraction, and quiz scoring.

---

## 4. Key Security & Architectural Constraints
- **Server-Side Security:** All Gemini API keys and MongoDB connection strings remain strictly server-side. No credentials are exposed to the client.
- **Strict Grounding & Citations:** Answers generated by the LLM must be backed by retrieved passages, citing verified source documents and page numbers.
- **Vector Consistency:** Both ingestion and query embeddings utilize `gemini-embedding-001` with 768 dimensions.

---

## 5. MongoDB Atlas Vector Search Index Configuration

Create a Vector Search index named `vector_index` on the `chunks` collection:
```json
{
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 768,
      "similarity": "cosine"
    },
    {
      "type": "filter",
      "path": "documentId"
    }
  ]
}
```
